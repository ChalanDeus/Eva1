# Ethos - Tienda Gamer

Este proyecto fue realizado para la asignatura de Desarrollo FullStack II.

La idea principal fue crear una tienda web enfocada en productos tecnológicos y gamer, utilizando HTML, CSS y JavaScript.

## Descripción

Ethos es una tienda web donde se pueden ver productos como:

- Mouse gamer
- Teclados
- Audífonos
- Mousepad
- Micrófonos
- Controles

La página también cuenta con registro de usuarios, inicio de sesión y un carrito de compras.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

El proyecto cuenta con las siguientes funciones:

- Página principal
- Página de productos
- Formulario de registro
- Formulario de inicio de sesión
- Validación de formularios con JavaScript
- Carrito de compras
- Agregar productos al carrito
- Eliminar productos
- Vaciar carrito
- Calcular el total de la compra
- Botón de pago
- Mensajes personalizados para algunas acciones
- Diseño responsive
- Menú de navegación fijo
- Video de YouTube integrado
- Favicon personalizado
- Cambio del título de la pestaña cuando el usuario cambia de ventana
